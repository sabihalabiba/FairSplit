
# FairSplit
### An Intelligent Task Allocation and Workload Balancing System

FairSplit is a Java-based, terminal-driven application developed using Object-Oriented Programming (OOP) principles.

The system aims to distribute tasks fairly by considering team members' skills, availability, and existing workload.

## Main Features
- Team and member management
- Task creation and management
- Skill-based task assignment
- Workload analysis and fairness tracking
- Task redistribution
- Deadline and progress tracking
- Local data storage

## Technologies
- Language: Java
- Programming Paradigm: OOP
- Interface: Terminal / Console
- Storage: Offline / Local
